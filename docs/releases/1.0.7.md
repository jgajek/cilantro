# CILantro 1.0.7

CILantro 1.0.7 improves large Reactor sample analysis and fixes recursive recovery when supplied libraries are needed by the parent but absent from a child's references.

- Control-flow completion indexes branch inputs, instruction positions and local accesses instead of repeatedly scanning large method bodies. Constant folding avoids propagating unread integer temporaries while dispatcher store queries retain their complete facts.
- Dispatcher recovery processes independent methods with at most four workers. Per-method rewrite order, round limits, verification and rollback are preserved, and reports are published in input order.
- Field restoration builds control-flow graphs only for matching address uses, retaining the whole-module reflection and escape checks.
- Extracted children load only referenced libraries from the inherited pool. Explicit unrelated libraries supplied to the root remain errors; child library failures are recorded without discarding the root report or stopping sibling recovery.

The WMS managed child completed all 136 pass decisions and recursive recovery in **21m11s** in a local confirmation run. It emitted a cleaned assembly with structural verification passing, restored **25,361 method bodies** and **194,451 proxy calls**, and replaced all **24,780 protected string sites**. Two emission runs produced identical cleaned assembly bytes.

That reproduction used matching installer dependencies, `--no-devirtualize --keep-names`, and a 128-million-step declaration. Missing LumiSoft metadata must be supplied; increasing the interpreter budget alone does not resolve it. No passes or emission gates were bypassed. The timing is a local reproduction rather than an isolated paired benchmark.

VM reconstruction was disabled, the integrity verdict remains partial, and independent IL verification still reports type errors, including existing erased-signature helper errors exposed by inlining. Successful cleaned emission does not establish complete runtime deprotection or full IL verifiability. See [performance](../performance.md), [troubleshooting](../troubleshooting.md) and [compatibility](../compatibility.md) for scope and reproduction guidance.

Windows x64, Linux x64/ARM64 and macOS Apple Silicon/Intel archives include the CLI, MCP server and documentation. Verify downloads against `SHA256SUMS.txt`.
