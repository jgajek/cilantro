# CILantro 1.0.5

CILantro 1.0.5 expands recovery for official ConfuserEx 1.0.0 and ConfuserEx 2 (mkaring 1.6.0) builds. The CLI banner now draws the capital **L** in CILantro correctly.

- Restore normal and JIT anti-tamper method bodies, including JIT locals and exception clauses.
- Recover normal, dynamic and x86 constants; normal and dynamic resources; and mild and strong reference proxies. Translate proven x86 expression stubs to managed CIL.
- Neutralize supported startup checks and rebuild compressor payloads as standalone executables with their original entry points. The extracted original payload remains byte exact.
- Pin 51 benign protected captures across isolated, combined and packed profiles. The combined dynamic/JIT and x86/normal-tamper captures from both editions run like their source oracle on three inputs.

These measurements cover the named official builds and tested configurations. An unfamiliar or modified protection layer can still be reported as incomplete; inspect the per-file report before relying on a cleaned assembly.

Windows x64 and Linux x64 archives include the CLI, MCP server and documentation without requiring a separate .NET installation. Verify downloads against `SHA256SUMS.txt`.
