# CILantro 0.10.6

This regular release completes the agreed .NET Reactor unprotection goal for the frozen undamaged corpus and improves recursive recovery, protector removal and the readability of recovered CIL. Windows x64 and Linux x64 archives include the self-contained CLI and MCP server.

## Changes

- Continue recovery through supported native wrappers and managed bootstrap assemblies into embedded payloads. Reassemble supported managed wrappers with their recovered child bytes.
- Remove remaining proven Reactor string resolvers, proxy setup, integrity checks, guards, obsolete runtime helpers and owned protection resources while preserving application initialization effects and payload resources.
- Recover embedded dependencies and support explicitly reviewed, hash-bound upstream dependencies through `--reviewed-dependencies`.
- Restore erased parameter, field and receiver types using caller, writer and reference-body evidence. Preserve signatures and reject ambiguous or incompatible uses.
- Improve late branch cleanup, unused-private-helper removal, symbol/reference consistency and anti-disassembly metadata cleanup.
- Strengthen physical VM-retirement checks and document final corpus coverage and candidate dispositions.

## Validation and scope

- All **43 original roots** completed: 37 ordinary recoveries, three declared negative controls and three successful same-build explicit generic recoveries.
- All **28 undamaged hashes** from the captured 29-sample Vault Reactor inventory are covered. The previously accepted damaged NETReactorSlayer rewrite remains excluded; the inventory was not refreshed.
- Independent VM-removal checks pass **18 contexts covering all 14 intact virtualized identities**.
- Physical inspection covers **104 structurally verified managed outputs**, with no identified retained VM, proxy, string-resolver, guard, integrity, trial or dead-prefix machinery after candidate review.
- Application identity and captured-payload preservation checks pass across all 43 roots. All 12 occurrences of four reviewed SQLite dependency hashes preserve their bytes.
- **2,852 fast tests** pass, alongside focused checks and a 100-context saved-output replay. Release CI additionally tests the source before building both archives.

The preservation contract covers actual corpus application/payload behavior, permits deliberate protector-metadata removal and retains application switches. It does not promise arbitrary external/reflection compatibility or universal recovery of unseen samples. Malware was analyzed through static interpretation, metadata inspection and decompilation, without execution in the host CLR.

Retained application payload resources and original tiny application methods are not protector remnants. One resource-manager method retains 13 harmless discarded constants; this optional instruction polish does not retain a VM or dispatcher. IL-verifier warnings are not counts of remaining protections, and this release does not promise warning-free decompilation.

See the [status report](https://github.com/jgajek/CILantro/blob/v0.10.6/docs/status-report.md) for the completion decision and evidence summary. Detailed trial artifacts referenced there remain in the local analysis workspace; they are not bundled with the release.
