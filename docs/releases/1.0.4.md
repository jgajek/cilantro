# CILantro 1.0.4

CILantro 1.0.4 adds Dotfuscator recovery and expands Babel support so analysts can follow protected methods, decoded values and embedded stages in a .NET decompiler.

- **Dotfuscator 7.9:** recover managed v1 and native-key v2 strings, encrypted resources and culture satellites, control flow, debugging/integrity checks and reviewed Android Root Checks. Authenticate native-key companions as data and retire unused generated runtimes after recovery. Reviewed native companions cover Windows, Linux and macOS; see the [coverage guide](../compatibility.md#dotfuscator-coverage) for platform validation limits.
- **Babel 12.1:** restore encrypted methods across generic owners, inheritance, byref arguments and exception handlers. Recover password-protected and separately deployed method data, all seven advertised cipher choices, numeric arrays, hash-string caches, resources and bundled dependencies. Remove obsolete proxies, initialization paths and generated runtimes as their application consumers are resolved.
- **Deployment and signing:** write recovered dependencies beside the host, support explicit `--babel-code-source FILE` inputs and re-sign cleaned assemblies with matching `--signing-key key.snk` keys.
- **Analyst documentation:** clarify the README, shorten the compatibility guide and move implementation proofs and corpus history into a reference appendix.

Recovery validation passed **3,906 tests with zero failures**, with 37 unrelated private-fixture skips. Thirty Babel/Dotfuscator manifests account for 362 main entries and six external-code companions. All twenty-one Babel cipher captures match source/protected/cleaned execution, and all seven .NET 8 cipher recoveries produce byte-identical Windows/Linux analyzer outputs. See the [validation report](../status-report.md) and [trial-target audit](../babel-dotfuscator-targets.md).

Babel stream string encryption and Dotfuscator Shelf Life remain outside the trial coverage target. Unknown/custom decoders and unavailable runtime state can still leave recovery incomplete. Analysis never launches the sample or loads its code into the host .NET runtime.

Windows x64 and Linux x64 archives include the CLI, MCP server and documentation, without requiring a separate .NET installation. Verify downloads against `SHA256SUMS.txt`.
