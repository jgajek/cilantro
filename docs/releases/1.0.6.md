# CILantro 1.0.6

CILantro 1.0.6 adds self-contained releases for Linux ARM64 and macOS on Apple Silicon and Intel. Recovery behavior and protector coverage are unchanged from 1.0.5.

- Download `cilantro-linux-arm64.tar.gz` for ARM64 Linux, `cilantro-osx-arm64.tar.gz` for Apple Silicon Macs, or `cilantro-osx-x64.tar.gz` for Intel Macs.
- Linux and macOS releases build on matching native runners. Before packaging, each runs version and help checks, recovery of a benign source-built probe, JSON error validation and MCP initialization.
- Windows x64 and Linux x64 releases remain available. All five archives include the CLI, MCP server and documentation without requiring a separate .NET installation.

Verify downloads against `SHA256SUMS.txt`. See the [compatibility guide](../compatibility.md) for protector coverage and the [1.0.5 release notes](1.0.5.md) for the preceding recovery changes.
