# CILantro 0.10.4

This regular release completes VM-machinery removal for all 14 intact virtualized inputs in the current corpus. Cleaned assemblies retain reconstructed application CIL and captured payloads, with the interpreter types and VM data removed. Windows x64 and Linux x64 downloads include the self-contained CLI and MCP server.

## Changes

- Remove isolated, replaced VM engines and recovered delegate-proxy types even when unrelated application reflection prevents precise reachability analysis. Preserve live application references and unexplained numeric-token consumers.
- Recognize reflection lookups that use the same live member's module and metadata token, allowing safe metadata compaction. Remove VM-only data resources with recorded hashes and application-resource exclusions.
- Warn prominently in stdout and HTML reports when VM reconstruction is incomplete. Inputs damaged by other tools can remain unsupported; analysts are directed to the intact original.
- Strengthen coupled-startup, repeat-call, resolver, assembly-inventory, native-memory and model-array comparisons. Preserve raw disagreements alongside bounded application-contract evidence.
- Fix Windows long-path verification, remove malformed custom attributes with invalid constructors, preserve required initialization and remove the identified Reactor trial-expiry guard.
- Extract native Costura dependencies and managed/native PE images in resource entries. Include an optional helper for unpacking the observed native UPX dependencies with provenance and hashes.
- Add an emitted-metadata VM-removal gate and an updated corpus status report.

## Validation and scope

The targeted recovery sweep verifies **14/14 intact virtualized inputs**, including the three known virtualized child hashes. All **28 reconstructed bodies/programs** survive as CIL; all **14 VM data resources** are removed; every output passes structural verification and ILSpy disassembly/decompilation. All **36,036 surviving methods** retain their bodies, locals and exception handlers after accounting for recorded renames. **15 benign runtime comparisons** and **24 captured payload observations** pass.

The native stage removes **2,992 obsolete types and 12,726 methods**, retaining **32,752 unchanged methods**. Its **80 ordered dependency-resolution outcomes** still match, including loaded bytes and repeat-call identity. Additional removed Reactor support methods were reviewed separately from automatic VM/proxy classification. The recovery build passed **1,294 selected regression tests**; release checks additionally pass **14 reporting/version tests** and verify the warning on the damaged corpus input.

The accepted closure criterion covers the 14 intact inputs. The damaged NETReactorSlayer Lqcuzgc copy remains unsupported and receives a warning; its intact original recovers successfully. Repairing third-party damage is not a condition for closing this item. This is not a claim that every corpus goal is complete: native deprotection, exhaustive extraction, residual readability work and a refreshed full-corpus measurement remain separate work. The 44-root baseline and 29-sample Vault inventory were not refreshed by this targeted sweep.

Malware trials use static interpretation and decompilation, not host execution. Raw full-state reconstruction disagreements, bounded-test limitations and residual decompiler warnings remain visible. See the [status report](https://github.com/jgajek/CILantro/blob/v0.10.4/docs/status-report.md) and [corpus validation](https://github.com/jgajek/CILantro/blob/v0.10.4/docs/corpus.md).
