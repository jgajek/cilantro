# CILantro 1.0.0 preparation

Source metadata targets **1.0.0**. This is release preparation; no release has been published from this candidate.

## Analyst workflow

```text
cilantro sample.exe
cilantro sample.exe -o case/run-01
```

A normal run recovers supported .NET Reactor and ConfuserEx code and strings, rebuilds supported VM-backed methods, simplifies control flow, assigns readable names, removes proven protector helpers and follows embedded managed stages within fixed limits. Progress and a status file are automatic. Each trial keeps its artifacts in a fresh case folder; `-o DIR` selects a new or empty folder.

The console uses the Reveal text banner and colors for progress, results and review items. Windows console processing is enabled automatically; unsupported hosts and redirected output receive plain text. The README uses the Flow emblem and CILantro wordmark.

**OUTPUT** names the recommended assembly, offline HTML report and case folder. **NEEDS REVIEW**, **REMAINING** and **VALIDATION** retain recovery qualifications. A successful run is not a claim of complete unprotection or equivalent behavior.

`--help` covers common analyst workflows; `--help-all` includes specialist controls. `--json` writes one run/error object, and `--version` prints the version alone. See the [option reference](../quick-start.md) and [automation contract](../agents.md).
