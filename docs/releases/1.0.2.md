# CILantro 1.0.2

Analysis is faster across the pinned static corpus. On the measured Windows host, total corpus wall time fell from 1,131.6 seconds to a two-run midpoint of 457.7 seconds: a 59.5% reduction, or about 2.47 times as fast. All 24 corpus cases passed in both optimized runs, with all 110 detailed reports and VM listings matching the original build after excluding timings and output paths.

The changes reduce repeated metadata lookup and intrinsic selection, redundant dispatcher scans, exception-region allocation, saturated provenance work and VM snapshot allocation. The CLI and MCP hosts now enable server garbage collection. Server GC trades additional CPU and memory for lower elapsed time; runtime overrides remain available.

All 2,931 tests passed with private fixtures available, with zero failures or skips. Recovery budgets, independent trials, verification and rollback policies are preserved. The [performance report](../performance.md) records measurements, limitations and reproduction commands. Release archives include the timing and output-comparison scripts.

Windows x64 and Linux x64 archives include the CLI, MCP server and documentation. Verify downloads against `SHA256SUMS.txt`.
