# CILantro 0.10.2

This regular release improves VM reconstruction, removal of protector infrastructure, embedded-stage recovery, and the evidence analysts can use to assess cleaned output.

## Changes

- Recover an additional Reactor VM initializer previously hidden by no-ops between argument loads and the interpreter call. Helper substitution now removes the complete proven argument sequence and rejects control-flow entries into it.
- Run independent initializer proofs even when resource-based recovery supplies no bootstrap evidence. Honor declared step budgets for large proxy-initializer sets.
- Recognize assembly-only type-handle use without falsely exposing every member to reflection. Local spills qualify only when all reads are assembly lookups and their addresses do not escape; cleanup still requires deadness, attribution, and no surviving references.
- Compare lifted initialization helpers directly through their callers in cold-start and repeat-call trials, requiring both the original VM entry and rebuilt helper to be exercised.
- Localize differences in captured VM state while preserving aliases in the remaining state and checking for shared modeled objects across that boundary. Keep the full-state verdict visible.
- Correct default values for constructed generic reference types, extend embedded-child recovery, and improve bounded payload extraction across multiple roots, partial captures, and budget retries.
- Add reconstruction cleanup gates and document reproducible trials. Expand the README introduction with the tool's technical capabilities.

## Validation and limits

Development validation passed 859 selected regression tests and all 24 runnable corpus gates (13 Reactor 6, nine Reactor 7.5, and two ConfuserEx). Both new reconstruction gates passed and rejected deliberately weakened cleanup counts, missing helper evidence, and suppressed disagreement verdicts. Ten runtime cases matched a source-built benign Reactor 7.5 fixture. Malware corpus trials remained static.

Qbjuef cleanup removed 200 protector support types and 1,444 methods; Mlfhntkcvb.payload.Lqcuzgc cleanup removed 564 types and 2,930 methods. Method counts include methods in removed types. The latter's newly discovered 832-operation initializer rebuilt into 1,163 CIL instructions. Both outputs passed structural verification and ILSpy decompilation. Qbjuef's two extracted payload hashes were unchanged.

Additional helper trials matched captured non-VM state on cold start, with no shared modeled objects across the boundary, and full captured state on repeat calls. Full protected-state disagreement remains visible for VM initialization and debugger-guard removal. These bounded checks do not establish equivalence for every input or complete unprotection across the corpus; unsupported paths and inconclusive trials remain.

See [support and limitations](https://github.com/jgajek/CILantro/blob/v0.10.2/docs/compatibility.md) and [VM validation](https://github.com/jgajek/CILantro/blob/v0.10.2/docs/devirtualization.md).
