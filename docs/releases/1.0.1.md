# CILantro 1.0.1

The CLI startup banner now pairs an ASCII cilantro leaf with a larger CILantro wordmark and the tagline "Reveal the code. Follow the payload." The artwork uses plain ASCII for compatibility with classic Windows Command Prompt and retains plain-text output when redirected or when color is disabled.

This is a presentation update; analysis and recovery behavior are unchanged.

Windows x64 and Linux x64 archives include the CLI, MCP server, documentation, and SHA-256 checksums. Release packaging now includes the available release notes rather than a hard-coded 1.0.0 document.
