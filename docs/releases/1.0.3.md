# CILantro 1.0.3

Babel .NET recovery now exposes generated strings, numeric constants, token-bound delegate targets and encrypted/compressed resource streams. Detection recognizes the connected generated runtime, including supported Babel layers revealed after Reactor method-body or VM recovery. Recovery stays within the bounded interpreter; sample code is never loaded into the host CLR or launched.

- Recover literal string/key decoders early enough to reveal embedded payload names.
- Decode newer resource streams through independent interpretations of the sample's own decoder, with legacy DES envelope and assembly-bundle extraction support. Export decoded data with source/output hashes and a resource index.
- Resolve token-bound delegate adapters across constructors, closed generics and boxed value-type receivers. Preserve required type initialization and retain adapters whose original private-access or dispatch context cannot be expressed by ordinary direct calls.
- Recognize parameter-sourced application strings without treating them as unresolved protected lookups, and synchronize the framework reflection cache used by parallel interpretation.

All nine hash-pinned Babel corpus cases passed, recovering 17 streams without newly broken or worsened methods under differential Microsoft ILVerify checks. Zebekeadu.dll yields all 152 string sites, 461 numeric reads and both resource streams. The pin_mxi capture resolves all 2,353 delegate bindings, rewrites 1,990 adapters and retains 363 for their access/dispatch context. Its numeric resource `YQLy` is absent from the original capture, so those values remain unresolved; that limitation is an explicit corpus expectation.

Validation in `C:/cilantro-verify` passed the full Babel-enabled run (2,903 tests, 37 unrelated private-fixture skips), followed by 47 targeted manifest/schema/adapter/concurrency checks. After the version bump and final schema checks, the release rerun passed 2,904 tests with 37 skips; the separately completed Babel corpus gate was excluded from that rerun. The historical Rrdsk case and both ConfuserEx corpus cases also passed. Legacy assembly-bundle layouts use synthetic ground truth; the captured Babel streams contain runtime tables. See the [support guide](../compatibility.md#babel-net-coverage) for scope and remaining unsupported formats.
